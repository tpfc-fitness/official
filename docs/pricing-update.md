位置：`src/views/service/_components/03-courses.ejs` 第 01 項「私人教練課程」的右欄，取代目前的「新生方案」價格清單。團體訓練、自主訓練的價格維持原樣。

### 版面

- 預設收合，只露出一列：左邊「價格方案」，右邊小字「新生方案・正式方案」＋箭頭（展開時箭頭朝上）。這一列上下各一條細線，跟現有分隔線同色。
- 展開後兩塊：
  1. **新生方案**（標題右側小字「限購一次・先試試看」）
  2. **正式方案（一對一）**（標題右側小字「確定適合再續」）
- 每一列：左邊是方案名稱，名稱下方是灰色小字（總價等）；右邊是「每堂 X」，數字放大加粗（主視覺是單堂價，不是總價）。可以沿用 `.m-price-list` 的 dt／dd 結構與 `.m-price-list-term`。

### 一定要用原生 `<details>`／`<summary>`

跟 `views/faq/_components/02-list.ejs` 同一個理由：收合中的價格仍在 HTML 裡，搜尋引擎與 LLM 讀得到。不要用 JS 動態塞內容，也不要用 `display:none` 以外的方式藏（例如點了才 fetch）。

`summary` 要拿掉瀏覽器預設的三角形（`list-style: none` 與 `::-webkit-details-marker { display: none }`），改用自己的箭頭。
