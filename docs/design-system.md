# 樣式盤點與 Design System 草案

整理全站目前的文字字級、標題、按鈕與顏色，並提出統一字級的方案。

最後更新：2026-10-15

---

## 一、先搞懂：寫的 px 不等於畫面上的 px

這個專案所有 `px` 都會被 `postcss-pxtorem` 轉成 `rem`（`postcss.config.js`），
而 `html` 的 font-size 又依斷點跟著視窗寬度縮放（`src/assets/css/_common/framework.css`）。
所以 class 寫 `text-[14px]`，實際畫面大小 = 14 ×（下表倍率）。

| 斷點 | 寬度 | root font-size | 常見裝置的實際倍率 |
|---|---|---|---|
| `m` 手機 | < 740 | 16/375 vw | 375 → ×1.00、390 → ×1.04、430 → ×1.15 |
| `t` 平板 | 740–1001 | 16/768 vw | 768 → ×1.00、820 → ×1.07 |
| `pMin` 小桌機 | 1001–1366 | 16/1366 vw | **1024 → ×0.75、1280 → ×0.94** |
| `pMax` 桌機 | > 1366 | 16px 固定 | ×1.00 |

**重點：** 桌機寬度在 1366 以下時，整站會一起縮小。1280 的筆電，`p:text-[14px]` 實際只有 13.1px。
這可能是「字普遍偏小」的主因之一。版面寬度也是用 rem 算的，所以縮的不只是字，是整頁一起等比縮放。

> 寫 `PX`（大寫）可以讓 pxtorem 跳過不轉，需要固定像素時可用。

## 二、現況盤點

全站用到 **36 種**不同字級（11px ~ 120px），幾乎每個區塊都各自寫死數值，沒有共用的字級變數。
下表的數字順序是 `桌機 / 平板 / 手機`。

### 標題

| 角色 | 目前寫法 | 字級範圍 | 例子 |
|---|---|---|---|
| KV 主標（H1） | 各頁自己寫，`font-black` | 50–64 / 32–52 / 26–36 | 首頁 62/40/40、about 62/40/30、contact 54/34/26、ourteam 50/32/32 |
| 首頁段落大標（H2） | 各段自己寫，`font-black tracking-[-0.03~-0.05em]` | 46–72 / 34–42 / 26–32 | 課程 72/42、教練 64/40/32、學員推薦 46/36/28、learn-more 58/38/30 |
| 內頁段落標（H2） | `.resevation-h1`（m-reservation.css） | 40 / 32 / 32 | contact、faq、service 場租 |
| 內頁段落標（H2，另一套） | about、service 各自寫 `font-bold` | 34 / 26 / 22 | about 三段、service intro |
| 卡片／小標（H3） | 各自寫，`font-bold` | 18–28 / 16–24 / 15–21 | 首頁課程 24、service 課程 28/24/21、FAQ 18/17/15、about 18/16 |
| `.resevation-h2/h3/h4` | m-reservation.css | 32/28、24/22、18/16/14 | contact 頁 |
| 文章頁 | `.m-article-*`（m-article.css） | H1 54/42/32、H2 32/28/24 | 文章是目前最完整的一套 |

**問題：**
- 同樣是「段落標題」，至少有三套：首頁 `font-black` 46–72、`.resevation-h1` 40、about `font-bold` 34。
- `.resevation-h1` 手機 32px，比桌機縮得少；about 的段落標手機只有 22px。兩頁並排看落差很大。
- class 名稱 `resevation` 拼錯（少一個 r），而且已經不只用在預約頁。

### 內文

| 角色 | 字級範圍 | 例子 |
|---|---|---|
| 副標／導言 | 18–30 / 15–24 | 首頁 KV 副標 30/24、about KV 導言 20/17/15 |
| 內文 | **14–16 / 13–14** | about 內文 14/13、contact KV 15/13、首頁 closing 16/14 |
| 輔助說明 | 12–13 / 12–13 | footer 連結 14/12、價格註記 13/12 |
| Eyebrow（標題上方的英文小標，字距大） | **11–13**（不分斷點） | `text-[11px] tracking-[0.24em]` 出現 8 次 |

**問題：**
- 內文最常見的組合是 `p:text-[15px] tm:text-[13px]`，在 1280 筆電上實際是 14px，在 375 手機上是 13px。中文內文這個大小偏小，一般建議桌機 16–18、手機 15–16。
- Eyebrow 11px 而且淡色（55% 白），在手機上很難讀。
- 有 32 個檔案用到 11–13px。

### 按鈕（`m-btn`，src/_components/mBtn.ejs + m-btn.css）

三種樣式：

| 樣式 | 外觀 | hover |
|---|---|---|
| `--highlight` | 紅底 `#E12020` 白字 | 變深紅 `#C40000` |
| `--contain` | 白底黑字 | 變透明白字 |
| `--border` | 白框白字，箭頭前有分隔線 | 內層變白底黑字 |

尺寸沒有統一，每次使用都在 `style.main` 裡自己寫寬高和字級：

**問題：** 主要 CTA 已經自然收斂成「高 54/52/48、字 17/15、手機滿版」，但每處都是複製貼上；KV 和 footer 的按鈕比例不一致（footer 桌機高 38 卻是 18px 字）。

## 三、提案：統一字級

### 建議字級表

數字是**設計稿 px**（實際大小仍會乘上第一節的倍率）。

| Token | 角色 | 桌機 p | 平板 t | 手機 m | 字重 / 行高 | 現況 → 調整 |
|---|---|---|---|---|---|---|
| `display` | KV 主標 | 64 | 44 | 34 | 900 / 1.2 | 大致不變，統一 |
| `title-xl` | 首頁段落大標 | 56 | 40 | 30 | 900 / 1.25 | 46–72 收斂成一個 |
| `title` | 內頁段落標 | 40 | 32 | 26 | 700 / 1.4 | about 34→40；`.resevation-h1` 手機 32→26 |
| `h3` | 卡片、小節標題 | 24 | 21 | 19 | 700 / 1.4 | 18–28 收斂；FAQ 問題 18→20 另用 `lead` |
| `lead` | 副標、導言、FAQ 問題 | 20 | 18 | 17 | 700 / 1.6 | 小幅放大 |
| `body` | 內文 | **17** | **16** | **15** | 400 / 1.9 | 14–15 / 13 → **放大約 2px** |
| `small` | 輔助說明、footer 連結 | 15 | 14 | 14 | 400 / 1.7 | 12–13 → 14 |
| `eyebrow` | 英文小標 | 13 | 13 | 12 | 700 / 字距 0.2em | 11 → 12–13 |
| `btn` | 按鈕文字 | 17 | 16 | 16 | 700 | 統一 |

原則：
- 內文手機最小 15、桌機最小 16；任何字都不低於 12。
- 標題放大幅度小、內文放大幅度大：現在「標題很大、內文很小」的對比太強，內文放大後反而更好讀。
- 按鈕尺寸也收成兩種：`--lg`（主要 CTA：高 54/52/48）與 `--sm`（次要：高 44/44/42）。

### 落實方式

**做法 A：整站等比放大（快，但不建議單獨用）**
改 `framework.css` 的 root font-size，例如桌機 16 → 17。因為版面寬度也是 rem，結果是整頁放大 6%，等於瀏覽器 zoom，字和版面的比例完全沒變，容易把排版撐破。

**做法 B：建立字級 class，逐頁替換（建議）**
1. 新增 `src/assets/css/_common/typography.css`，用 `@apply` 定義 `.t-display`、`.t-title-xl`、`.t-title`、`.t-h3`、`.t-lead`、`.t-body`、`.t-small`、`.t-eyebrow`，每個 class 內含三個斷點的字級、字重、行高。在 `_library.css` 引入。
2. 逐頁把 `font-bold leading-[1.4] p:text-[34px] t:text-[26px] m:text-[22px]` 這類寫法換成 `t-title`。之後要調整全站字級只改這一個檔。
3. `.resevation-h1/h3/p` 改成沿用新 class，再慢慢移除。
4. `mBtn.ejs` 加 `size` 參數（`lg` / `sm`），尺寸寫進 m-btn.css，不再每次手寫寬高。

**搭配：小桌機縮放加下限**
1001–1366 之間整頁縮小這件事，可以只對文字加下限，例如 `.t-body { font-size: max(16PX, 1.0625rem); }`（大寫 PX 不會被轉 rem），版面照樣縮、字不會小於 16。

### 建議順序

1. 先做 `typography.css` 和按鈕 size，不動頁面 → 不影響線上。
2. 從內文和 eyebrow 開始換（最有感、風險最低），一次一頁，每頁對照桌機 1280／手機 390 截圖。
3. 再換標題，最後清掉 `.resevation-*`。
